# Mint Wave — App Store 스크린샷 가이드

> 6.7" 디스플레이 (iPhone 17 Pro / 17 Pro Max / 16 Pro Max) 기준 **1290 × 2796 px**
> 5장 필수 (10장까지 가능) — 5장만 잘 찍어도 OK
> 한국어 / 영어 각각 5장 = 총 10장

---

## 캡쳐 순서 + 화면

### 1️⃣ Hero — 첫인상 (가장 중요)
**화면**: `/home` (홈)
**왜**: 모디 마스코트 + 오늘의 감정 카드. 앱의 정체성 한 장.
**상태**: 인사말 한 줄 나오게. 시간대 적당히 (저녁 톤이 잘 어울림)
**텍스트 오버레이** (선택):
- 🇰🇷 "오늘, 호흡할 시간"
- 🇺🇸 "Today, a moment to breathe"

### 2️⃣ Music — 145가지 자연 사운드
**화면**: `/music` (사운드 믹스 화면)
**왜**: 핵심 기능. 자연 카테고리 카드 그리드 + "🌿 실제 자연 녹음" 배지 노출.
**상태**: 2-3개 사운드 활성 상태 (재생 인디케이터 살아있게), 타이머 UI 노출
**텍스트 오버레이**:
- 🇰🇷 "겹쳐 만드는 나만의 사운드"
- 🇺🇸 "Layer your own soundscape"

### 3️⃣ Breathing — 호흡 가이드
**화면**: `/breathing` 의 호흡 시각 (큰 원 부풀어 오를 때)
**왜**: 디자인 강점. 가장 시각적으로 예쁜 화면.
**상태**: 4-7-8 호흡 중간, 큰 원이 풀 사이즈
**텍스트 오버레이**:
- 🇰🇷 "4-7-8 · 박스 · 8-2-8"
- 🇺🇸 "4-7-8 · Box · 8-2-8"

### 4️⃣ Sleep — 수면 통계 + 타이머
**화면**: `/sleep` 또는 `/me` 의 SleepCalendar 부분
**왜**: 데이터 기반 기능. 주/월/연 토글 + 캘린더 그리드 보임.
**상태**: 몇 주치 수면 기록 채워진 상태 (테스트 데이터)
**텍스트 오버레이**:
- 🇰🇷 "잠든 시간이 한 눈에"
- 🇺🇸 "See your sleep at a glance"

### 5️⃣ Emotion Cards — 12가지 감정
**화면**: `/home` 의 감정 카드 그리드 (스크롤한 상태) 또는 `/release`
**왜**: 다른 사운드 앱과 차별점 — "감정"으로 진입.
**상태**: 모든 감정 카드 (12개) 보이게
**텍스트 오버레이**:
- 🇰🇷 "12가지 감정, 맞춤 사운드"
- 🇺🇸 "12 moods, curated sound"

## 캡쳐 방법 (실제 폰)

```bash

# AirDrop 으로 Mac 으로 받기
```

또는 시뮬레이터:
```bash
# Xcode → Simulator → File → New Screen Recording
# iPhone 17 Pro Max (6.7") 시뮬레이터 사용
```
